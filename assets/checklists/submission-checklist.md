# 投稿前检查表（submission-checklist）

> 供 S7 报告第 9 节与作者最终自查。逐项确认后再投稿。

## 稿件内容
- [ ] 研究问题明确，Introduction 含文献综述与研究缺口
- [ ] Contributions 显式声明（3–5 条 bullet）
- [ ] 方法可复现（参数表、伪代码/算法、数据来源）
- [ ] 含对比实验 / baseline（或已诚实说明不可得）
- [ ] 含灵敏度 / 鲁棒性分析
- [ ] 结论回应研究问题，不夸大

## 格式与规范
- [ ] 已替换为目标期刊**官方**模板（非 bundled 骨架）
- [ ] 摘要 / 关键词 / 字数符合 `constraints`
- [ ] 参考文献格式符合 `reference_style`，数量合理
- [ ] 图表分辨率达标（通常 ≥300 dpi），矢量图优先
- [ ] 全文符号一致，`symbol_map` 无冲突

## 诚信与合规
- [ ] 所有数值/结论均有原文或实验支撑，无 `[[MISSING]]`/`[[UNVERIFIED_REF]]`
- [ ] 所有引用可验证（DOI/来源），无编造
- [ ] 声明 AI 辅助使用情况（按期刊 `ai_disclosure_policy`）
- [ ] 伦理审批 / 数据可用性声明齐备（如需）
- [ ] 作者贡献、利益冲突声明、基金资助已填

## 文件交付
- [ ] 主稿（LaTeX 源 + 编译 PDF / 或 Word）
- [ ] `references.bib`
- [ ] 图件原文件
- [ ] Cover letter
- [ ] Highlights / Graphical abstract（若期刊要求）
- [ ] `conversion-report.md`（本工具产出，供自查留痕）
