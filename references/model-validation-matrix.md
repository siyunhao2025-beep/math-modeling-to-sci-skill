# 模型原型与再验证矩阵

## 使用原则

先根据全文、数据结构和模型假设识别主/辅原型。关键词只能生成候选，不能替代方法判断。每篇稿件按主张风险选择验证，不机械堆满所有项目。

共通底线：

- 建立最简可信基线；
- 比较使用同一数据、预处理、划分、指标和计算预算；
- 报告绝对差与不确定性，不只报相对提升；
- 结果、配置、种子和失败运行落盘；
- 只有声称模块贡献时才做消融；
- 经验阈值不能冒充本研究结论。

## 1. Optimization / 优化

**核心主张**：可行性、最优性或近优性、成本/收益改进、求解效率。

**最低验证**：

- 约束可行率与违反幅度；
- 与朴素策略、业务规则或经典求解器公平比较；
- 关键权重、预算或约束的敏感性；
- 随机算法多种子分布与收敛行为。

**高风险时增加**：小规模精确解/穷举、下界/上界、KKT 或对偶界、外部实例、复杂度与运行成本。

**常见错误**：只展示最好一次；启发式结果称“最优”；改变约束后不重算基线。

## 2. Evaluation / 综合评价与排序

**核心主张**：指标体系合理、权重可解释、排序稳定、决策结论不依赖任意口径。

**最低验证**：

- 指标方向、量纲和标准化审计；
- 权重扰动与排名稳定性；
- 至少一种替代赋权/排序方法；
- AHP 等方法的内部一致性（适用时）。

**高风险时增加**：专家间一致性、bootstrap 排名区间、已知外部排序对照、缺失指标情景。

**常见错误**：把主观权重写成客观事实；只报最终名次；雷达图替代稳定性分析。

## 3. Prediction / 预测与回归

**核心主张**：对未见样本有预测价值、误差可接受、优于合理基线。

**最低验证**：

- 与均值/持续性/线性/经典时序等朴素基线比较；
- 按数据结构划分：时间滚动、主体留出或分组留出；
- MAE/RMSE 等误差与残差诊断；
- 预测区间或不确定性。

**高风险时增加**：外部数据、时间外推、校准分析、分层性能、概念漂移、特征/模块消融。

**常见错误**：随机切分时间序列；在测试集调参；只报 R²；把插值能力写成外推能力。

## 4. Classification-CV / 分类、聚类与计算机视觉

**核心主张**：识别性能、泛化、公平性或分群可解释性。

**最低验证**：

- 无主体/图像近重复泄漏的划分；
- 混淆矩阵和类别级 precision/recall/F1；
- 类别不平衡处理前后对比；
- 独立测试或适配的交叉验证。

**高风险时增加**：外部域、校准、置信度、亚组误差、标注者一致性、特征或模块消融。

**常见错误**：仅报 accuracy/AUC；同一对象跨训练测试；聚类结果无稳定性或外部解释。

## 5. Mechanism / 机理与动力学

**核心主张**：方程结构合理、参数可辨识、模型解释或机制与数据一致。

**最低验证**：

- 方程、边界/初值和参数来源；
- 与观测/实验或公认理论关系对照；
- 残差结构与参数敏感性；
- 可辨识性或参数相关性分析。

**高风险时增加**：守恒量/维度检查、外推验证、替代机制比较、独立实验、结构不确定性。

**常见错误**：拟合良好就声称机制成立；不可辨识参数被赋予强解释；数值稳定性未检查。

## 6. Signal / 信号处理

**核心主张**：去噪、检测、定位或谱估计性能与稳定性。

**最低验证**：

- 合成/理论信号的可控对标；
- SNR、MSE、频率/定位误差等适配指标；
- 不同噪声水平、采样率或窗口设置；
- 与经典方法同口径比较。

**高风险时增加**：真实外部信号、失配噪声、时频分辨率权衡、计算延迟、硬件约束。

**常见错误**：只展示漂亮波形；滤波参数从测试结果反调；把处理后信号当原始观测。

## 7. Spatial-Graph / 空间、图与网络

**核心主张**：空间泛化、路径/网络可行性、拓扑或空间关系合理。

**最低验证**：

- 空间分块或区域留出，避免邻近泄漏；
- 几何/图约束和连通性检查；
- 与已知路径、精确小实例或外部分区对照；
- 对坐标、距离和空间尺度敏感性。

**高风险时增加**：Moran's I 等空间结构诊断、跨区域外部验证、网络扰动、边/节点删除稳健性。

**常见错误**：普通随机交叉验证；坐标系或距离单位混用；地图视觉替代定量验证。

## 8. Simulation / 随机仿真与离散事件

**核心主张**：仿真输出收敛、情景比较稳定、分布假设合理。

**最低验证**：

- 多随机种子/多次重复和置信区间；
- 重复次数增加时的收敛；
- 参数/分布假设敏感性；
- 与解析结果、经典模型或已知案例对照。

**高风险时增加**：方差缩减、代理模型误差、极端情景、输入不确定性传播、独立实现互验。

**常见错误**：一次运行给点估计；用仿真“证明”输入假设；把模拟样本量当真实样本量。

## 主张—验证配对

| 主张类型 | 最低证据 | 常见第二证据 |
|---|---|---|
| “优于基线” | 同口径对比 + 不确定性 | 外部数据或多种子重复 |
| “模块有效” | 针对该模块的消融 | 机制/误差分解 |
| “稳健” | 预先说明的扰动矩阵 | 外部场景或替代口径 |
| “可解释机制” | 机制预测与数据一致 | 替代机制排除/干预证据 |
| “可推广” | 域外或时间外验证 | 多数据源/多地区/多任务 |
| “最优” | 可证最优性或上下界 | 精确小实例/对偶界 |
