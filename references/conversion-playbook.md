# 数学建模报告 → SCI 研究稿转换手册

## 1. 先做转化可行性裁决

不要默认任何获奖或完整建模报告都适合投稿。按以下顺序判断：

1. **对象是否真实**：题目是否对应现实系统、公开数据、真实实验或可推广机制？
2. **问题是否外部化**：离开竞赛题面后，研究问题仍有意义吗？
3. **证据是否可扩展**：是否有数据、代码或结果支持补做验证？
4. **贡献是否可辨认**：相对已有方法，差异和收益能否被测量？
5. **边界是否诚实**：模拟、案例或单数据集结论是否被限制在实际范围内？

以下任一项构成硬阻塞：

- 只有方法设想，没有真实运行或结果；
- 核心数据不可获得且无法合法重建；
- 关键数字或图表来源不明；
- 所谓创新只是堆叠模型名称或竞赛排名；
- 结论必须依赖新实验，但作者无法提供；
- 目标主张超出数据覆盖且无法收窄。

## 2. 建立内容处置账本

对原报告每个章节、图、表、公式、结论和附录逐项登记：

| 处置 | 适用情况 | 要求 |
|---|---|---|
| `retain` | 直接进入正文 | 保留语义和来源定位 |
| `adapt` | 内容保留但需换体裁/位置 | 记录前后位置和改写理由 |
| `supplement` | 对复现重要、正文过重 | 在正文保留必要回链 |
| `drop` | 与研究问题无关或重复 | 写理由；实质性内容需作者确认 |
| `pending` | 尚无法判断 | 阻止 F 门通过 |

“零损失”指零静默损失，不是把竞赛报告每一段都塞进论文。题面复述、团队分工、竞赛专用评分细节和重复推导通常不应占据 SCI 正文，但必须在账本中留下去向。

## 3. 从任务驱动改为问题驱动

将以下竞赛结构：

```text
问题一 → 模型一 → 答案一
问题二 → 模型二 → 答案二
问题三 → 综合方案
```

改造成研究结构：

```text
现实/科学问题
→ 现有知识与方法的具体缺口
→ 本文提出的模型或分析框架
→ 可复现的验证证据
→ 有条件的结论与适用边界
```

每个子问题只保留三种角色之一：

- 支撑主研究问题；
- 作为方法验证或敏感性分析；
- 移入补充材料或删除。

不要按原“问题一/二/三”机械保留章节名，除非各子问题本身构成清晰的递进研究设计。

## 4. 形成研究定位

使用六格定位：

| 字段 | 回答 |
|---|---|
| Problem | 哪个现实/科学对象，在什么条件下，存在什么问题？ |
| Gap | 现有工作在哪个对象、条件、方法或证据层面不足？ |
| Approach | 本文采用什么可复现方法解决？ |
| Evidence | 哪些数据、对比、验证和不确定性支持？ |
| Contribution | 新增了什么可观察、可比较、可复用的价值？ |
| Boundary | 结论只在哪些数据、场景和假设下成立？ |

贡献候选按四象限整理：

- **问题创新**：新的约束、对象、尺度或决策目标；
- **方法创新**：针对已证明短板的结构性改进；
- **证据创新**：新的数据、验证、对照或不确定性分析；
- **应用创新**：在新场景中经验证的可迁移价值。

“首次”“首创”“显著优于”必须有可验证证据。否则改成范围更窄的表述。

## 5. 章节重构

| 建模报告内容 | SCI 去向 | 常见补强 |
|---|---|---|
| 题目背景/问题重述 | Introduction 的问题背景 | 文献定位、研究缺口 |
| 基本假设 | Methods / Limitations | 依据、可检验性、影响 |
| 符号说明 | Methods 或补充材料 | 单位、范围、统一命名 |
| 模型建立 | Methods | 基线、选择理由、复杂度 |
| 模型求解 | Methods + Reproducibility | 代码、参数、环境、种子 |
| 结果展示 | Results | 不确定性、公平对比、边界 |
| 模型检验 | Results / Supplement | 与主张一一对应的验证 |
| 优缺点 | Discussion | 替代解释、适用条件、限制 |
| 推广 | Discussion / Future work | 只保留有证据的可迁移性 |

写作顺序优先使用：claim map → Methods/Results → Figures/Tables → Discussion → Introduction → Abstract/Conclusion。避免先写宏大引言再寻找证据填充。

## 6. 三种转化结论

### A. 可直接进入补验证

适用于问题清楚、数据代码完整、主要结果真实，但期刊级验证不足。进入 R。

### B. 需要重构研究问题

适用于材料完整，但论文仍是“答题说明”。先完成 O，不急于写英文正文。

### C. 暂不适合转化

适用于数据/结果缺失、创新依赖包装或核心结论不可追溯。输出：

- 当前证据能支持的最强产物；
- 不能支持的主张；
- 最小补数据/补实验清单；
- 预计新增时间与依赖；
- 可替代方案，例如技术报告、方法说明或数据论文。
