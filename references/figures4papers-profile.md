## 3. 审计到的图形谱系

上游案例覆盖以下视觉问题，可用于选择图形家族，但不能替代数据与 claim 的匹配判断：

| 图形家族 | 可表达的问题 | 本 skill 的判定 |
|---|---|---|
| 简单、分组、堆叠、横向柱图 | 离散组比较、组成、排序 | `ADAPT`；柱长表达绝对量时默认从零开始，堆叠只用于可解释的整体—部分关系 |
| 误差柱与带误差的组间比较 | 估计值及不确定性 | `ADAPT`；必须标注 SD、SE、CI 或其他定义，并给出样本单位与样本量 |
| 差值箭头、改进标记、进度标注 | 两个状态之间的方向和幅度 | `ADAPT`；同时给出起点、终点、单位与绝对差，避免只报相对提升 |
| 趋势线、透明度渐变线、面积填充、时间轴 | 随时间或有序变量变化 | `ADAPT`；透明度只能辅助，主要系列仍需线型、点型或直接标签区分 |
| 概率分布、密度曲线、样条或 KDE 形状 | 分布位置、离散度、多峰与演化 | `ADAPT`；说明带宽、平滑或插值，并尽可能叠加样本或分位数信息 |
| 注释热图、扩散/相似度矩阵 | 二维结构、局部模式、关系强度 | `ADAPT`；使用可解释的共同色标、缺失值编码和对比度自适应注释 |
| 按列归一化热图 | 各列内部排序 | `ADAPT`，但必须披露每列独立归一化；颜色不得被解读为跨列同量级 |
| 雷达图 | 同方向、同量纲或合理归一后的少量指标概览 | 条件式 `ADAPT`；异质指标或依赖多边形面积比较时 `REJECT` |
| 轴外标签、无轴概念图、示意流程 | 机制、关系或叙事结构 | `ADAPT`；显式标为 conceptual schematic，不得伪装成观测或拟合结果 |
| 2D 球面明暗、球面插值路径、流形示意 | 几何直觉、路径或嵌入空间概念 | `REFERENCE-ONLY`，除非研究对象确实有对应几何含义且实现、参数可复现 |
| 自定义 3D 箭头、多势阱曲面、孔洞或地形 | 向量场、能量面或空间机制 | `REFERENCE-ONLY`；3D 透视不得遮挡证据，必要时附等高线或二维切片 |
| 多面板论文组合图 | 多种证据在一张主图中协作 | `ADAPT`；每个面板承担独立证据角色，统一编号、对齐、尺度和图例语义 |

上游实现主要使用 Python、Matplotlib 与 NumPy，部分案例依赖 SciPy、数学排版或系统字体。仓库未形成可直接安装、依赖完备且有测试保障的绘图库，因此本 skill 不导入其运行时代码。

## 4. 布局与信息层级

### `ADAPT`

- 先由 `scientific_question` 与 `claim_ids` 决定面板，再选择网格；不要先套模板再寻找内容。
- 多面板图使用稳定的 A/B/C… 编号、统一边距和基线；跨面板共享的颜色、线型与符号保持同义。
- 系列较多时可设置独立图例面板或共享图例区，避免图例遮挡数据。直接标签优于让读者反复来回查图例。
- 对齐共享坐标轴，删除真正重复的刻度文字，但保留单位、尺度和必要的参考线。
- 轴外注释和留白用于建立阅读顺序；装饰元素不得压过数据墨水。
- 面向单栏或双栏的最终物理尺寸设计，再决定字体、线宽和标记大小；以导出后的实际尺寸复核可读性。
- 宽幅组合图可用于阶段演化或多基准对比，但应先拆分为逻辑组，再判断是否确有横向画布的必要。

### `REJECT`

- 把超宽、超高画布或大量空白当作通用论文风格；特别是接近海报尺寸的绝对画布直接缩入论文后会令文字和线条失真。
- 仅为视觉对称而填入没有证据增量的面板。
- 在不同面板中让相同颜色或符号改变含义，或让图例顺序与图层顺序不一致。

## 5. 配色与冗余编码

### 通用规则（`ADAPT`）

- 先定义语义角色，再选颜色：主方法、基线、改进、风险、背景与高亮各自保持稳定。
- 类别数据用离散且色盲友好的色板；有序量用单调顺序色板；围绕有意义中点的正负变化才用发散色板。
- 颜色不能成为唯一信道。用线型、点型、纹理、边框、直接标签或面板位置提供冗余编码。
- 文字压在色块上时根据相对亮度选择深色或浅色文字，并逐格检查，而不是使用一个固定文字颜色。
- 控制饱和度：高饱和色只用于关键证据或异常点，背景与次要系列退到中性层级。
- 同时检查常见色觉缺陷模拟、灰度打印、投影和小尺寸导出。

审计中观察到的上游色彩角色包括深蓝/中蓝主系列、浅绿改进层级、柔和红色对照、灰色基线、金色高亮，以及青绿/紫色的双系列对照。出现过的代表性色值包括 `#0F4D92`、`#3775BA`、`#DDF3DE`、`#AADCA9`、`#8BCF8B`、`#F6CFCB`、`#E9A6A1`、`#B64342`、`#CFCECE`、`#FFD700`、`#42949E` 与 `#9A4D8E`。这些值仅用于识别来源风格，属于 `REFERENCE-ONLY`；默认产物应根据数据语义、可访问性和期刊规范重新选色。

### `REJECT`

- 只靠红—绿区别优劣或状态。
- 只靠透明度区分主次系列，导致打印、投影或叠加后无法辨认。
- 为保持品牌色而牺牲顺序、发散或类别色标的科学含义。

## 6. 字体、标注与线条

### `ADAPT`

- 上游常见 Helvetica/无衬线风格、约 15–16 pt 的紧凑标注、约 24 pt 的大字号标题以及约 2–3 pt 的强调线宽，可作为层级线索，不能作为固定输出值。
- 字号、线宽和标记尺寸应按最终物理版面设定：正文可读性优先，标题只比轴标签高一个清晰层级。
- 建立可移植字体回退链，覆盖拉丁字符、中文、数学符号和负号；导出前检查字体是否嵌入或被正确转换。
- 数学排版保持变量、单位和上下标规则一致。系统 LaTeX 只能是可选增强，不能成为未声明的硬依赖。
- 面板字母、轴标签、单位、图例与注释使用统一语法和大小写；缩写在图注首次解释。
- 线条在最终尺寸下仍可见，但不以粗线遮住置信带、散点或相邻曲线。

### `REJECT`

- 假定每台机器都安装 Helvetica、LaTeX 或同一数学字体。
- 为“醒目”给所有元素同等粗细、饱和度和字号，破坏视觉层级。

## 7. 导出与复现

上游快照以 PNG 为主，常见 300 dpi，个别高密度柱图使用 600 dpi，并包含 3 个 PDF；不能据此宣称存在完整 SVG 工作流。

### `ADAPT`

- 线条、文字和几何图优先导出 PDF/SVG 等矢量格式；包含密集栅格、影像或极多点时同时生成高分辨率 PNG/TIFF。
- 记录画布物理尺寸、分辨率、色彩模式、字体、依赖版本、随机种子和输入数据摘要。
- 使用紧边界裁切前检查轴外标签、图例、面板字母和误差条端帽是否被截断。
- 对最终文件执行视觉复核：打开矢量文件检查嵌字与透明度，按投稿尺寸渲染并检查文字、线条、纹理与颜色。
- 文件名稳定并与 figure contract、生成脚本和源数据一一对应；不要覆盖唯一原始导出。

### `REJECT`

- 把“300 dpi”当作所有图的充分条件；纯矢量图的清晰度不由这个数字单独决定。
- 只保存交互窗口截图，或在未记录尺寸和字体的情况下依赖本机渲染。

## 8. 误差条与统计标记

### `ADAPT`

- 在轴标签、图例或图注中写清误差条是标准差、标准误、置信区间、分位区间还是重复实验范围。
- 报告 `n`、独立样本单位、重复层级和区间估计方法；配对数据、簇集数据或交叉验证折次不得当成独立样本。
- 区间与点估计使用一致尺度；对数轴、归一化或反变换后的区间要说明计算空间。
- 样本量允许时叠加原始点、轻量分布或分位数，避免只展示均值与端帽。
- 显著性标记必须能追溯到检验、比较集合和多重比较处理；效应大小与不确定性优先于星号。

### `REJECT`

- 不说明含义的误差条、被坐标边界截断的区间、用端帽制造过高精度，或用误差条暗示不存在的独立重复。

## 9. 热图专项

### `ADAPT`

- 原始值可比时使用共同归一化和单一色条；只有问题明确要求“列内相对位置”时才按列归一化。
- 按列或按行独立归一化后，在标题、色条或图注明示 `within-column` / `within-row`；跨列或跨行的颜色比较被禁止。
- 顺序量使用感知单调色板；有意义的零点或基准点才采用发散色板，并令中点与科学语义一致。
- 单元格文字根据背景亮度切换颜色，控制有效数字；矩阵过密时优先聚类、分面或只标关键格。
- 缺失、不适用、未计算和真实零值使用不同编码；排序、聚类距离与链接方法写入图注。

### `REJECT`

- 每列使用不同色域却共用一个看似统一的色条。
- 用彩虹色板表达顺序量，或让注释文字与背景没有足够对比。

## 10. 雷达图专项

### 条件式 `ADAPT`

- 仅在指标数量较少、方向一致且归一化依据可解释时使用；保留可读刻度和原始量纲查表入口。
- 写清 min–max、目标区间、排名或其他变换；越大越差的指标先统一方向并披露。
- 比较对象过多时拆成小倍图或只保留少数预注册对象，使用线型、点型和直接标签补充颜色。

### `REJECT`

- 用多边形面积对异质量纲指标作总体优劣判断；面积会随轴顺序、量纲和归一化改变。
- 隐去刻度、变换规则或基准范围后宣称“全面领先”。
- 当重点是逐指标精确比较时使用雷达图；改用点图、平行坐标、小倍图或带数值的表格。

## 11. 概念图、流形与 3D

### `ADAPT`

- 概念图明确标注 `conceptual schematic`、`illustrative` 或“非按比例”，并区分观测数据、模型输出和解释性图元。
- 箭头只表达已定义的方向、变换或依赖；颜色、距离、曲率和阴影若无定量含义，不得在图注中暗示有量纲。
- 合成数据或示意几何写明生成规则与参数；若展示实际嵌入或路径，保存输入、算法和随机种子。
- 3D 结果附二维投影、等高线、切片或可查询数值，使遮挡和视角不决定结论。

### `REFERENCE-ONLY`

- 球面明暗、球面线性插值、瑞士卷式嵌入、自定义 3D 箭头、势阱或孔洞曲面等具体视觉配方。只有当它们与研究对象的数学结构一致时，才从零实现并进入人工科学复核。

### `REJECT`

- 用逼真的光照、透视或曲面装饰制造“真实测量”的错觉。
- 让视角选择隐藏反例、负值、区间或模型失效区域。

## 12. 模板化落地策略

可进入本 skill 的通用资产应当是独立实现的规则，而不是上游副本：

- `ADAPT`：语义色彩角色、共享/独立图例布局、面板编号、字体回退、对比度自适应标签、颜色加线型/纹理的冗余编码、矢量加位图双导出、图注披露清单。
- `REJECT`：非零截断柱图作为默认、红绿唯一编码、透明度唯一编码、无说明误差条、未披露的分列热图归一化、以雷达面积作总体结论、固定超大画布。
- `REFERENCE-ONLY`：原始脚本、PNG/PDF、论文数据、精确调色与构图、复杂球面/流形/3D 配方，以及任何需要逐行或像素级复刻的案例。

每次使用本画像仍需回到 `references/figure-contract.md`：图形首先回答科学问题，其次才优化版式。目标期刊的当前官方规范、数据语义与可访问性要求优先于本画像中的风格观察。
