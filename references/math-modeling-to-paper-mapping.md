# 数学建模报告 → 学术论文 结构映射

> 供 S2 学术化改写参考。建模报告通常面向竞赛/课程，结构松散、口语化、重计算轻论证；
> SCI 论文要求 IMRaD 结构、明确的研究缺口与创新点、可复现的方法与实验。

## 1. 典型建模报告章节 → 论文语义角色

| 建模报告常见章节 | 论文 semantic_role | 改写要点 |
|------------------|-------------------|----------|
| 问题重述 / 题目理解 | `problem_statement` | 提炼为严谨的问题定义，给出记号与假设 |
| 模型假设 | `assumptions` | 假设须可检验、与后续推导对应 |
| 符号说明 / 符号表 | `notation` | 与 IR `symbol_map` 对齐，全文唯一 |
| 模型建立 / 模型构建 | `model_formulation` | 用数学语言重述，补充推导链 |
| 求解 / 算法 / 求解步骤 | `methodology` / `algorithm` | 给出可复现步骤与复杂度/收敛性 |
| 模型求解结果 / 数值结果 | `results` | 区分"结果"与"分析"，用图表承载 |
| 灵敏度分析 / 稳定性 | `sensitivity_analysis` | 必须存在，否则实验完整性不足 |
| 模型评价 / 优缺点 | `discussion` / `limitations` | 客观评价，不回避局限 |
| 改进方向 / 推广 | `future_work` | 具体、可操作 |
| 结论 / 总结 | `conclusion` | 回应研究问题，凝练贡献 |

## 2. 竞赛报告常缺、论文必备的要素

1. **Introduction + 研究缺口**：竞赛报告几乎没有文献综述与研究动机。
   S2 必须补 Related Work 与 "existing methods fail at X, we address X"。
2. **Explicit Contributions**：通常在 Introduction 末尾用 bullet list 声明 3–5 条创新点。
3. **Sensitivity / Robustness**：建模报告常只给一组结果；论文需参数鲁棒性分析。
4. **Baselines / 对比**：无对比实验则 G3 实验完整性会扣分，G2 禁止编造对比。
5. **Reproducibility**：数据来源、参数表、随机种子、代码/数据可用性声明。

## 3. 改写禁忌（反幻觉）

- 不得为"看起来更完整"而编造实验、数据、对比、引用。
- 原文没有的数值结论 → 标记 `[[MISSING]]` 并登记 gap。
- 原文没有的文献 → 联网检索并验证；验证失败保留 `[[UNVERIFIED_REF]]`。
- 数学语义零改动：公式、上下标、常数、符号含义不得变更（G2-03/04）。

## 4. 篇幅与密度

- 建模报告常冗长描述步骤；论文应提高信息密度，删去操作细节、保留方法本质。
- 摘要独立成段，150–250 词（受期刊 `abstract_max_words` 约束），含目的/方法/结果/结论四要素。
