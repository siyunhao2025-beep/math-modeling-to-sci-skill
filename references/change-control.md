# 变更传播与回退

## 1. 变更分级

| 级别 | 典型改动 | 回退起点 |
|---|---|---|
| L0 | 排版、拼写、参考文献格式 | G/E 局部复核 |
| L1 | 收窄主张、调整语气、补限定条件 | O/G；同步摘要、结论、图注、claim map |
| L2 | 重跑分析、改筛选、误差、图表或数字 | R；重做结果、图表、正文与 E |
| L3 | 改模型、参数、数据源、设计、基线或指标 | O/R；全部下游失效 |
| L4 | 改研究问题、缺口、核心证据或目标体裁 | F/O；重新定位并重走下游 |

判断不了时按更重一级处理。目标期刊变化通常是 E 级变更，但若新期刊体裁或篇幅要求改变论证范围，应回到 G，必要时回到 O。

## 2. 依赖传播

标准传播链：

```text
source/forensics
→ research positioning/model profile
→ validation plan/results
→ claim map/figures/manuscript/citations
→ journal fit/review/submission package
```

任何上游哈希变化都使已登记下游标为 stale。脚本可计算工件级传播，但一句话是否动摇整段论证仍需语义复核。

## 3. 回退 SOP

1. 冻结当前版本，不覆盖旧结果。
2. 记录变更内容、原因、旧值→新值和触发证据。
3. 运行 `python scripts/forge.py impact <workspace> --changed <path...>`。
4. 从建议的最早阶段正向重做。
5. 重建 claim、figure、citation 与 journal 相关工件。
6. 重新过阶段门并更新哈希基线。

禁止手改结果文件里的数字；禁止看到结果后静默修改阈值；禁止只更新正文而不更新摘要、结论、图表和补充材料。

## 4. 审稿意见路由

| 审稿要求 | 回退 |
|---|---|
| 补文献、解释范围 | O/G |
| 补基线、消融、稳健性 | R |
| 改数据、模型或实验设计 | F/O/R |
| 改图表表达但不改数字 | G |
| 期刊格式、声明、匿名 | E |

审稿人要求新数据而作者无法提供时，不编造结果。可收窄主张、补限制、解释超出范围，或明确无法完成并让作者裁决。
