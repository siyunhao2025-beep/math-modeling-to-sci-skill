# FORGE 与旧 S1–S8 兼容映射

旧运行时保留用于输入解析、模板渲染和确定性检查。新框架负责统一研究逻辑。

| FORGE | 旧工件/阶段 | 说明 |
|---|---|---|
| F | S1 输入解析、IR、G1 | 增加资产处置账本与零静默损失 |
| O | S2 学术化改写前半、S3 部分评估 | 先完成研究定位和贡献上限，再写正文 |
| R | 原稿代码/结果 + 新 validation plan | 旧流程缺少按模型原型的再验证，应在 S2 写作前补齐 |
| G | S2 写作、S3 评估、S6 校验、S8 claim/citation/figure | 以 claim map 统一多个检查器 |
| E | S4 期刊匹配、S5 模板、S8 journal/reviewer/preflight、S7 报告 | 当前官方证据优先于本地 seed |

推荐运行顺序：

```text
F(S1 + forensics)
→ O(research positioning)
→ R(revalidation)
→ G(S2/S3 + claim/citation/figure + S6)
→ E(S4/S5 + reviewer/preflight + S7)
```

不要把 S3 的加权分数当作 O/R/G 门的替代，也不要把 S6 编译通过当作科学结论通过。
