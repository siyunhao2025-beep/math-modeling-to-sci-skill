# 图表契约：按证据覆盖，而非按数量凑图

## 1. 先问每张图证明什么

为每个顶层 Figure 或 Table 建立契约：

| 字段 | 要求 |
|---|---|
| ID | 稳定且唯一 |
| scientific_question | 这张图回答的唯一科学问题 |
| claim_ids | 支持的正文主张 |
| evidence_role | 机制、主结果、比较、验证、不确定性、边界等 |
| source_data | 真实源数据/结果文件 |
| script | 可重建图的脚本或明确生成流程 |
| panels | 每个面板提供的不同证据 |
| caption_claim | 图注可核验结论与边界 |
| risks | 可能误导的轴、截断、平滑、尺度、配色 |

没有独立科学问题或证据增量的图不进入正式稿。同一数据换成折线、柱状和雷达图不算三项证据。

## 2. 常见证据角色

- 研究/方法路线图：仅在复杂流程确实需要总览时使用；不是每篇论文强制图 1。
- 数据与质量审计：分布、缺失、偏差、覆盖范围。
- 模型/机制示意：明确标为 conceptual schematic，不能冒充观测。
- 主结果：直接回答研究问题。
- 公平比较：基线、主模型和成本/风险并列展示。
- 验证：残差、外部验证、精确解、交叉验证等。
- 不确定性：置信区间、参数/情景传播、稳定性。
- 边界与失败：模型失效区、负结果或敏感条件。

缺少某角色不自动失败；是否需要由 claim map 和模型原型决定。

## 3. 图、表或正文的选择

- 精确数值、参数、样本量和多指标对照优先表；
- 趋势、分布、空间结构、关系与不确定性优先图；
- 一两个关键数值直接写正文；
- 重复信息不同时出现在图和表，除非两者分别承担趋势与精确查值。

## 4. 科学与视觉检查

每张图检查：

- 轴名、单位、尺度、零点、方向与数据一致；
- 误差条/置信带含义和样本单位明确；
- 统计显著性与效应大小不混淆；
- 过滤、平滑、插值、截轴和归一化被披露；
- 不使用颜色作为唯一编码；使用线型、点型、纹理或直接标签冗余编码；
- 色盲友好且黑白打印仍可区分；
- 矢量优先，位图满足目标期刊分辨率；
- caption 独立可读，说明对象、条件、指标、结论和边界；
- 正文明确引用并解释，不把图扔给读者自己猜。

脚本只能检查文件、字段、尺寸和链路；图是否科学、是否误导必须逐张人工/视觉复核并记录 reviewer 与时间。

### 4.1 发布锁：依赖、最终尺寸与可编辑性

新建工作区的 `04-manuscript/figure-manifest.json` 使用 schema 2.1。每张正式图件除原有科学字段外，还必须声明：

| 字段 | 要求 |
|---|---|
| `source_data` | 一个或多个工作区相对路径；不得越出工作区 |
| `script` | 可重建图件的脚本路径 |
| `outputs` | 实际交付文件的工作区相对路径 |
| `sha256` | 分别锁定每个源数据、脚本和输出文件；任一文件变化即阻塞 |
| `final_size.slot_class` | 例如 `single-column`、`double-column` 或期刊规定的命名槽位 |
| `final_size.width_mm` / `height_mm` | 正数，表示真正投放时的物理尺寸 |
| `editability.class` | `live-vector-text`、`outlined-text`、`embedded-raster`、`mixed` 四选一 |
| `visual_review` | reviewer、时间、最终容器、复核宽高以及 `editability_checked=true` |

“有 SVG/PDF 文件”不等于“完全可编辑”：文字转轮廓、位图嵌入或混合交付必须如实分类。复核大画布上的预览也不能替代最终栏宽/容器检查。schema 2.0 工件保持兼容，但 G 阶段会提示其缺少发布锁；升级应在重建并复核图件后完成，不能只补字段或刷新哈希。

## 5. 数量与变更

不要预设“标准论文必须 N 张图”。建议数量来自未覆盖的关键 claim，而非历史平均或营销效果。

新增图时必须新增至少一种：独立分析、实验、证据角色或决策问题。删除图时检查其 claim 是否仍被表格、正文或其他图充分覆盖。

结果、模型或研究问题变化后，相关图、图注、正文、摘要和结论一并失效。按 `references/change-control.md` 回退。

## 6. 外部案例知识路由

需要选择图种、设计多面板布局、配色与字体、处理误差条/热图/雷达图或制定导出策略时，按需读取 `references/figures4papers-profile.md`。其中 `ADAPT` 表示可独立实现的通用原则，`REJECT` 表示不进入默认工作流，`REFERENCE-ONLY` 表示只查阅、不复制上游资产。该画像不能覆盖本文件的科学证据契约，也不能覆盖目标期刊的当前官方规范。
